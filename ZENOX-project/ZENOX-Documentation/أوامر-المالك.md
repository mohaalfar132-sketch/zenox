# أوامر المالك في ZENOX

هذه أوامر مقترحة لواجهة المالك، ويمكن تنفيذها نصيًا أو صوتيًا بعد تحويل الصوت إلى نص. لا يُنفذ الأمر الحساس دون عرض التفاصيل وطلب التأكيد.

## الحسابات والمستخدمون

- أرسل دعوة إلى البريد …
- عطّل حساب المستخدم …
- أعد إرسال دعوة المستخدم …
- غيّر صلاحيات المستخدم …
- اسمح للمستخدم … باستخدام البحث.
- امنع المستخدم … من استخدام أداة …
- اعرض تقرير المستخدمين والدعوات.

## المساعدون والنماذج

- أنشئ مساعدًا باسم الباحث.
- غيّر صورة المساعد الدراسي.
- اجعل المساعد العام يتحدث بالمصرية.
- اجعل نمط المجادلة يعرض الرأي والرأي المقابل.
- أوقف أداة إنشاء الصور.
- أضف نموذجًا أو أداة جديدة بعد مراجعة الترخيص.

## السياسة

- امنع الألفاظ البذيئة.
- إذا سأل المستخدم عن تصنيع قنابل، ارفض وقدم بديلًا آمنًا.
- اسمح بالمعلومات الطبية التثقيفية فقط مع تنبيه.
- اعرض قاعدة التعلم المقترحة ولا تعتمدها.
- اعتمد القاعدة على المساعد الدراسي فقط لمدة أسبوع.

## الموقع والروابط

- أنشئ صفحة جديدة عن سياسة الخصوصية.
- غيّر لون الموقع إلى Midnight Aurora.
- أنشئ رابط تنزيل Android للإصدار … لمستخدم محدد.
- أنشئ رابطًا صالحًا لاستخدام واحد.
- أوقف كل روابط الإصدار القديم.
- افحص الموقع وأعطني تقريرًا.
- فعّل كلمة مرور للموقع لاحقًا.

## التطوير والأمن

- راجع الكود بحثًا عن ثغرات داخل ZENOX.
- أنشئ خطة إصلاح ولا تنفذها.
- جهّز نسخة تجريبية واعرض الملفات المتأثرة.
- افحص روابط التنزيل والجلسات والصلاحيات.
- اعرض ما فعلته وما لم تفعله.
- أوقف المهمة.
- ارجع إلى النسخة السابقة.

## إنشاء التطبيقات

- أنشئ تطبيق ملاحظات يعمل عبر الإنترنت.
- أضف تسجيل دخول بالدعوة فقط.
- أضف محادثة صوتية.
- أنشئ لوحة تحكم للمدير.
- اختبر المشروع وأعطني تقرير الأخطاء.
- لا تنشر التعديل قبل موافقتي.
