# حزمة مشروع ZENOX

هذه الحزمة توثيقية وليست نسخة تنفيذية من التطبيق. تم إعدادها لحفظ المواصفات والأوامر والتصور المعماري قبل بدء البناء.

## المحتويات

- `مواصفات-منصة-الذكاء-الاصطناعي.md`: المواصفات الكاملة وآخر القرارات.
- `أوامر-المالك.md`: أوامر الإدارة المقترحة بصياغة عربية واضحة.
- `سجل-طلبات-المالك.md`: ملخص ما طلبه المالك وقراراته النهائية.
- `معمارية-Cpp.md`: تصور طبقات النظام التي يمكن تنفيذ أجزاء منها بلغة C++، وليس كود التطبيق التنفيذي.
- `قرار-التنفيذ.md`: حدود ما تم وما لم يبدأ بعد.
