# قالب بيئة وأسرار ZENOX

هذا المجلد يحتوي على أسماء متغيرات البيئة المطلوبة فقط، ولا يحتوي على أي قيمة سرية فعلية.

## الاستخدام المحلي

انسخ الملف إلى جذر المشروع باسم `.env` ثم أدخل القيم من مدير الأسرار أو من إعدادات الخادم الخاص بك:

```bash
cp ZENOX-environment-template/.env.example .env
chmod 600 .env
```

لا ترفع `.env` إلى Git ولا تضفه إلى أي ملف ZIP يتم مشاركته. ملف `.env.example` مناسب للمشاركة لأنه يحتوي على أسماء المتغيرات فقط.

## القيم التي يجب حمايتها

تُعد `MANUS_JWT_SECRET` و`JWT_SECRET` و`MANUS_API_KEY` و`BUILT_IN_FORGE_API_KEY` و`DATABASE_URL` ورموز Google Drive أسرارًا. خزّنها في مدير أسرار أو إعدادات الخادم، ولا تضعها في تطبيق الجوال.

إذا كان المشروع يعمل عبر إعدادات WebDev، أدخل الأسرار من إعدادات المشروع المحمية بدل كتابة القيم داخل الكود. بعد إدخال القيم، أعد تشغيل خادم API وشغّل فحوص المشروع.

## التحقق بدون كشف القيم

```bash
for key in MANUS_PROJECT_ID MANUS_API_URL MANUS_API_KEY DATABASE_URL; do
  if [ -n "${!key:-}" ]; then echo "$key=SET"; else echo "$key=MISSING"; fi
done
```

هذا الأمر يطبع حالة المتغير فقط، ولا يطبع قيمته.
